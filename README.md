# Tic Tac Toe

A browser-based Tic Tac Toe game built as part of **The Odin Project** JavaScript curriculum.

## Features

- Two-player gameplay
- Custom player names
- Win detection
- Tie detection
- Restart game functionality
- Prevents moves on occupied tiles
- Prevents further moves after the game ends

## Built With

- HTML5
- CSS3
- JavaScript (ES6)

## JavaScript Concepts Practiced

- Factory Functions
- Module Pattern (IIFE)
- Encapsulation
- DOM Manipulation
- Event Listeners
- Game State Management
- Array Methods

## Project Structure

- **GameBoard** – Stores and manages the board state.
- **GameController** – Handles game logic, player turns, winner and tie detection.
- **DisplayController** – Manages UI updates and user interactions.
